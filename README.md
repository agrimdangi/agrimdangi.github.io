# Agrim Dangi — Portfolio & Technical Blog

A responsive, dark-themed personal portfolio and technical blog, built with HTML, CSS and vanilla JavaScript for GitHub Pages.

## Structure

- `index.html` — personal portfolio
- `blog/` — blog index and articles
- `assets/` — shared styles and JavaScript

## Deploy to GitHub Pages

Recommended: create a repository named **`agrimdangi.github.io`** under the GitHub account `agrimdangi`, then upload the contents of this folder to the repository root.

1. Create the repository as public.
2. Upload all files and folders in this project (including `.nojekyll`).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages deployment to complete.

Expected URLs:
- Portfolio: `https://agrimdangi.github.io/`
- Blog: `https://agrimdangi.github.io/blog/`

If you use a repository with another name, the site URL will include that repository name, for example `https://agrimdangi.github.io/REPOSITORY-NAME/`. Relative links in this site are designed to work in a project subdirectory too.

## Personalize before publishing

- Replace the LinkedIn placeholder URL in `index.html` with your actual profile.
- Add a professional email address if you want one displayed.
- Review the education, program and project descriptions for accuracy.
- Add project screenshots only if they do not expose private data.
- Keep real employee information, credentials, API keys and `.env` files out of the repository.
